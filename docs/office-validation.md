# Office validation checklist

This preview does not yet certify Claude Enterprise or Gemini automatic tracking.

1. Follow the [installation guide](installation.md) on Windows 10/11 x64, using the installer or portable ZIP as your organisation permits. No developer toolchain is required. The installer can download missing WebView2; the portable build requires it already installed. Record the release tag being tested. All connections start off.
2. In Settings, name the Claude account and workspace. Choose experimental Claude Code access only if your office account already uses that CLI and your organisation allows it. Alternatively open the isolated usage window and try Settings → Usage.
3. Compare each separate monthly budget with the member's actual Settings → Usage view: used spend, denomination, limit, remaining amount and exact reset date. Record only sanitized numbers and quota labels; never send session files or tokens.
4. Test a monthly reset on a date other than the first, an overage, missing limit, unlimited allocation, disabled spend and expired login. Do not mark enterprise supported merely because a synthetic fixture passed.
5. For Gemini, open the signed-in Usage limits page, capture and compare each displayed window. A missing counter stays unavailable. Test whether embedded Google authentication permits sign-in; manual snapshot is the fallback.
6. Compare Codex windows with the installed Codex usage view. Verify ordinary ChatGPT is never labelled with Codex percentages.
7. Check the widget and detail panels at 100%, 125%, 150%, 200% scaling and on monitors with different DPI. Drag between monitors, snap each edge, disconnect a monitor and restart. Verify tray show/hide, quit, remembered placement, always-on-top and opt-in startup.
8. Check system light/dark, opaque mode, reduced motion, keyboard focus, long account labels, multiple accounts and connection errors. Enable alerts and verify only downward threshold crossings notify.

Record app version, Windows version, plan type, source and timestamp. Use manual snapshots until a tier's actual source has been verified. Auth-dependent tests and physical multi-monitor/DPI tests require these devices and accounts.
